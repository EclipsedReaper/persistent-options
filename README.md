# Persistent Options

A client-side mod that remembers and restores your settings so you don't have to reconfigure them every time you install a new modpack.

## Features
- Automatically saves settings when you leave the options menu
- Restores your preferred settings on game startup
- Works across instances and modpacks
- Fabric and NeoForge support via Architectury

## Requirements
*   One of the following Minecraft + loader combinations:
    *   **Fabric** 1.20.1–1.21.11
    *   **Forge** 1.20.1–1.20.4
    *   **NeoForge** 1.20.4–1.21.11
*   Architectury API
